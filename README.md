# IP Collab BI

日本娱乐 IP 与手游联动的地区表现仪表盘。

公开网页：<https://hiro-zhu-5x.github.io/ip-collab-bi/>

展示口径按平台独立记录：iOS 使用 App Store 的“免费下载榜·游戏榜”和“畅销榜·游戏榜”，Android 使用 Google Play 游戏分类免费榜与畅销榜，中国小游戏按微信、抖音、QQ、支付宝等具体渠道分开。当前已接入微信小游戏畅销榜；该渠道没有统一免费下载榜，显示为“未提供”。完整榜单读取成功但没有排名显示为“未入榜”；只公开 Top 范围时，产品未出现显示为“公开范围外”，不能据此判定未入榜；读取失败显示为“未读取”，尚未尝试显示为“待抓取”。

数据来源分工：iOS 以七麦为主、AppMagic补缺，Android 使用 AppMagic 的 Google Play 游戏分类榜；微信小游戏以应用宝公开畅销榜为主，并用 MomoRank 免费 Top 10 交叉核对；官方公告用于核验联动时间和地区。页面默认展示最近 90 天，也可用开始日期、结束日期查看已回填的历史记录。日期范围只筛选联动项目和趋势，不会隐藏产品当前的渠道读取状态。尚未补齐历史榜单的记录显示为“历史榜单待补”，不按 0 分参与 IP 影响力评分。

截至 2026-09-03，本地历史库共生成 4,699 条“平台×地区联动记录”，覆盖 1,897 个历史联动项目、145 款产品、795 个“平台×产品×地区”配置及 270,335 个日级趋势点。地区体系覆盖中国大陆、香港、台湾、日本、韩国、美国，以及 SEA-6（新加坡、马来西亚、泰国、印度尼西亚、菲律宾、越南）共 12 个独立市场。

东南亚活动记录遵循两层核验：商店存在只代表当地有真实客户端；只有当地官方公告确认后，才代表联动实际同期举行。由全球/多地区记录扩展出的东南亚候选会明确标注“待当地公告核验”，不会把日本活动直接当作东南亚已确认活动。当前数据仍不是全球穷尽清单。

微信小游戏当前为首轮试点，仅配置《向僵尸开炮》和《口袋奇兵》。APP服公告不能自动视为微信小游戏服同步；因此现有三条历史联动均标注“微信小游戏服适用范围待核验”，不参与 IP 影响力评分。日级榜单从 2026-09-02 起积累。
