# IP Collab BI

日本娱乐 IP 与手游联动的地区表现仪表盘。

公开网页：<https://hiro-zhu-5x.github.io/ip-collab-bi/>

展示口径按平台独立记录：iOS 使用 App Store 的“免费下载榜·游戏榜”和“畅销榜·游戏榜”，海外 Android 使用 Google Play 游戏分类免费榜与畅销榜；中国大陆 Android 因没有统一商店总榜，改用官网、商店、TapTap 及新闻媒体公开证据，并明确区分跨平台/综合商业指标。中国小游戏仅分微信小游戏与抖音小游戏，且两者不混算：微信使用MomoRank人气Top 10及应用宝畅销Top 20，抖音使用MomoRank热门Top 10及畅销Top 10。完整榜单读取成功但没有排名显示为“未入榜”；只公开 Top 范围时，产品未出现显示为“公开范围外”，不能据此判定未入榜；读取失败显示为“未读取”，尚未尝试显示为“待抓取”。产品及联动已经核验、但渠道AppID尚未确认的项目也会作为候选收录，显示为“渠道/AppID待核验”，不进行榜单匹配且不参与影响力评分。

数据来源分工：iOS 以七麦为主、AppMagic补缺；海外 Android 使用 AppMagic 的 Google Play 游戏分类榜；中国大陆 Android 使用官方上架证据与中国新闻媒体披露，未公开数字显示“名次未公开”，跨平台/综合指标不参与标准单商店排名评分；微信小游戏以应用宝公开畅销 Top 20 为主，并用 MomoRank 畅销 Top 10 交叉核对，同时记录MomoRank人气Top 10；抖音小游戏记录MomoRank热门Top 10与畅销Top 10；官方公告用于核验联动时间和地区。页面默认展示最近 90 天，也可用开始日期、结束日期查看已回填的历史记录。日期范围只筛选联动项目和趋势，不会隐藏产品当前的渠道读取状态。

截至 2026-09-04，本地历史库共生成 8,014 条“平台×地区联动记录”，覆盖 1,950 个历史联动项目、163 款产品、1,203 个“平台×产品×地区”配置及 650,583 个日级趋势点。地区体系覆盖中国大陆、香港、台湾、日本、韩国、美国，以及 SEA-6（新加坡、马来西亚、泰国、印度尼西亚、菲律宾、越南）共 12 个独立市场。

东南亚活动记录遵循两层核验：商店存在只代表当地有真实客户端；只有当地官方公告确认后，才代表联动实际同期举行。由全球/多地区记录扩展出的东南亚候选会明确标注“待当地公告核验”，不会把日本活动直接当作东南亚已确认活动。当前数据仍不是全球穷尽清单。

小游戏库现已配置《向僵尸开炮》《口袋奇兵》《贪吃蛇大作战》《太空杀》《地铁跑酷》《球球大作战》《开心消消乐》《元梦之星》《蛋仔派对》《叫我大掌柜》《一步两步》《几何王国》《冒险大作战》《球球英雄》《开间小店》《星之旅人》《天天爱消除》《逃跑吧！少年》《我的休闲时光》《途游休闲捕鱼》，合计 20 款产品、24 个“产品×渠道”版本，其中微信 18 个、抖音 6 个；已收录 56 个联动项目，对应 65 条“渠道×联动”记录。发现范围为2018年至今，当前最早符合口径的联动记录为2018-07-27。APP服公告不能自动视为小游戏服同步；未确认渠道AppID或未明确小游戏服适用范围的历史项目均标注为候选，不进行榜单匹配且不参与 IP 影响力评分。微信畅销日级榜单从2026-09-02起积累，微信人气榜、抖音热门榜和抖音畅销榜从2026-09-03起积累。
