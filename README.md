# IP Collab BI

日本娱乐 IP 与手游联动的地区表现仪表盘。

公开网页：<https://hiro-zhu-5x.github.io/ip-collab-bi/>

展示口径仅包含 App Store iPhone 的“免费下载榜·游戏榜”和“畅销榜·游戏榜”。读取成功但没有排名显示为“未入榜”，读取失败显示为“未读取”，尚未尝试显示为“待抓取”。

数据来源分工：七麦提供榜单主数据，AppMagic用于交叉验证与历史联动发现，官方公告用于核验联动时间和地区。页面默认展示最近 90 天，也可用开始日期、结束日期查看已回填的历史记录。尚未补齐历史榜单的记录显示为“历史榜单待补”，不按 0 分参与 IP 影响力评分。

截至 2026-09-02，历史联动库包含 1,696 个项目，产品目录为 113 款手游；地区体系覆盖中国大陆、香港、台湾、日本、韩国、美国，以及 SEA-6（新加坡、马来西亚、泰国、印度尼西亚、菲律宾、越南）共 12 个独立市场。SEA-6 已通过 Apple 官方目录确认 62 款产品、307 个“产品×地区”上架组合，并在七麦中逐地区读取榜单。

东南亚活动记录遵循两层核验：App Store 存在只代表当地有真实客户端；只有当地官方公告确认后，才代表联动实际同期举行。由全球/多地区记录扩展出的东南亚候选会明确标注“待当地公告核验”，不会把日本活动直接当作东南亚已确认活动。当前数据仍不是全球穷尽清单，也不含 Android 榜单。
