# IP Collab BI

日本娱乐 IP 与手游联动的地区表现仪表盘。

公开网页：<https://hiro-zhu-5x.github.io/ip-collab-bi/>

展示口径仅包含 App Store iPhone 的“免费下载榜·游戏榜”和“畅销榜·游戏榜”。读取成功但没有排名显示为“未入榜”，读取失败显示为“未读取”，尚未尝试显示为“待抓取”。

数据来源分工：七麦提供榜单主数据，AppMagic用于交叉验证与历史联动发现，官方公告用于核验联动时间和地区。页面默认展示最近 90 天，也可用开始日期、结束日期查看已回填的历史记录。尚未补齐历史榜单的记录显示为“历史榜单待补”，不按 0 分参与 IP 影响力评分。
